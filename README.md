# Makieta systemu KFS (LDIT)

Klikalna makieta systemu zarządzania dofinansowaniami KFS. Działa w przeglądarce, bez serwera: dane demonstracyjne są w bazie SQLite ładowanej w przeglądarce, a zmiany zapisują się lokalnie, osobno u każdego odwiedzającego.

**Strona:** https://clickless-sp-z-o-o.github.io/ldit-makieta/

Logowanie: hasło do wszystkich kont demonstracyjnych to `demo`, lista kont jest na ekranie logowania.

To repozytorium jest kopią publikacyjną. Źródłem makiety, dokumentacją i testami jest prywatne repozytorium projektu; zmian nie wprowadza się tutaj bezpośrednio.
